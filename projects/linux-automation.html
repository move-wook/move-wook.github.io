Linux 서버 운영 자동화

LinuxShell ScriptCRONSFTPSlack API

배경

인증서 만료 안내를 담당자가 수동으로 확인하고 공지하는 방식이라 누락 위험이 컸고, 백업도 주기적인 수작업에 의존하고 있었다. 디스크 사용량 역시 사후에 발견되는 경우가 많아 스토리지 포화로 인한 장애 가능성이 있었다.

해결

  • 인증서 만료일을 DB 기반으로 자동 추적·발송하는 파이프라인을 구축하고, 유료 메일 API를 네이버 메일 API로 전환
  • Shell Script, CRON, SFTP 기반의 백업 자동화 파이프라인을 구축 — 일자별 압축 분할 및 보관 주기 관리 로직 적용 (13개 서버, NAS 대상)
  • 디스크 사용률 구간별(60% 주의 / 70% 경고 / 80% 위험) 실시간 Slack 알림 체계를 구축해 사후 수습이 아닌 사전 차단 구조로 전환

결과

반복 CS 업무 제거, 메시지 운영비 약 70% 절감, 스토리지 포화로 인한 장애 사전 차단

사용 기술

Linux, Shell Script, CRON, SFTP, Slack API, 네이버 메일 API
