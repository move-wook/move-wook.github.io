연세대학교 카드 발급 시스템 유지보수

JavaMyBatisMariaDB

배경

학생 및 교직원 대상 카드 발급용 관리자 시스템을 1인으로 전담해 유지보수 및 기능 개발을 담당했다.

장애 대응

카드 발급을 취소할 때 DB Lock이 발생하는 문제를 확인했다. 원인을 추적한 결과 트랜잭션 미처리가 원인으로 식별되어, 롤백 로직을 추가해 해결했다.

개선

  • 기숙사 출입용 학생 정보 연동 API 구현
  • 단순·루틴 업무를 효율화하는 기능을 기획·개발
  • DB 접속용 콘솔 프로그램을 개발해 운영 편의성 향상

결과

운영 시간 1시간 이상 단축

사용 기술

Java, MyBatis, MariaDB
