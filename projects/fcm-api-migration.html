FCM 푸시 API 마이그레이션

JavaSpringREST APIFirebase Cloud Messaging

배경

Firebase(FCM) 푸시 API 사양이 변경되면서, 기존 방식으로 발송하던 푸시 알림이 정상적으로 수신되지 않는 이슈가 발생했다.

해결

단순 재발송 등 임시 대응에 그치지 않고, 변경된 API 사양을 직접 파악해 신규 명세 기준으로 발송 로직 전체를 마이그레이션했다. API 구조 전환을 주도적으로 진행했다.

결과

푸시 미수신 이슈 해결 및 알림 도달률 안정화

사용 기술

Java, Spring, REST API, Firebase Cloud Messaging(FCM)
