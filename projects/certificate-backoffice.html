배경

전자증명서 서비스를 운영하기 위한 내부 관리(백오피스) 기능이 필요했다.

담당 역할

  • 전자증명서 카테고리 추가 및 연동처 관리 기능 구현
  • 서비스 점검 기능 추가 및 백오피스 서버 운영
  • Spring Boot + jQuery 기반 서버 사이드 로직 개발

사용 기술

Java, Spring Boot, jQuery

느낀 점 서비스 화면만큼 운영자가 매일 쓰는 관리 화면의 완성도도 중요하다고 생각합니다. 눈에 잘 띄지 않는 백오피스 기능이라도, 운영 현장에서 실제로 겪는 불편을 줄이는 방향으로 설계하려 했습니다.
