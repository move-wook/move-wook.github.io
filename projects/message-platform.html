미라벨소프트

공통 메시지 중계 플랫폼 통합

JavaSpring BootREST API

배경

서비스에서 발송하는 SMS·알림톡·푸시가 4개 프로젝트에서 외부 문자 큐에 각자 접근하는 파편화된 구조로 운영되고 있었다. 정책이 바뀔 때마다 4개 프로젝트를 전부 수정해야 하는 비효율이 반복됐다.

해결

별도 요청이 있기 전에 이 반복되는 비효율을 먼저 인지하고, 사내에 공통 플랫폼으로의 확장을 직접 제안했다. Spring Boot 기반 REST API 중계 플랫폼으로 구조를 일원화하고, 요구정의부터 DB 설계, 통합 발송 API 개발까지 담당했다.

결과

신규 프로젝트가 생기더라도 단일 API 호출만으로 메시지 발송이 가능해져 프로젝트 간 결합도가 대폭 감소

사용 기술

Java, Spring Boot, REST API
