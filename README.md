# move-wook.github.io

임동욱 개인 포트폴리오 사이트. 정적 HTML/CSS/JS, GitHub Pages로 배포.

## 현재 상태
- 구조/콘텐츠 1차 완료 (이력서·자소서 기준 사실 반영)
- **디자인 폴리싱은 의도적으로 보류** — 지금은 최소 베이스라인 스타일만 적용

## 로컬 확인
```bash
open index.html
```

## 배포
`https://<username>.github.io` 저장소는 GitHub Pages가 별도 설정 없이 자동 배포한다
(Settings → Pages에서 소스가 `main` 브랜치로 잡혀있는지만 확인).
